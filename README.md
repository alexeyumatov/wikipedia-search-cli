# Практическая работа 2. Консольный поиск по Википедии

Программа считывает поисковый запрос, ищет статьи в русской Википедии через её API
и выводит список результатов. После выбора номера статья открывается в браузере.
Для разбора JSON используется Gson (лежит в `lib`).

## Запуск

Открыть проект в IntelliJ IDEA (добавить `lib/gson-2.11.0.jar` как библиотеку) и запустить `wiki.Main`, или из терминала:

```
javac -encoding UTF-8 -cp lib/gson-2.11.0.jar -d out $(find src -name "*.java")
java -cp out:lib/gson-2.11.0.jar wiki.Main
```

На Windows в `-cp` вместо `:` нужен `;`. Нужна Java 17+.

## Структура

- `model` - результат поиска и ссылка на статью
- `api` - запрос к API Википедии и разбор ответа
- `browser` - открытие статьи в браузере
- `console` - меню, чтение ввода и вывод результатов

Пустой запрос, ошибки сети, отсутствие результатов и неверный номер статьи
обрабатываются без падения программы. Для выхода введите `выход`.
